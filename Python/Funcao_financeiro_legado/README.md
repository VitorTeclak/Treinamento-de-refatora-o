# Refatoração de Sistema Financeiro em Python

Este repositório demonstra a refatoração de um código legado escrito em Python,
com foco em legibilidade, separação de responsabilidades e previsibilidade de comportamento.

## Objetivo
Simular um cenário real de código legado:
- Função monolítica
- Variáveis com nomes pouco descritivos
- Lógica duplicada
- Baixa manutenibilidade

E aplicar princípios de Clean Code para torná-lo mais compreensível e sustentável.

## Estrutura

- **ANTES/**  
  Código original, funcional, porém com alto acoplamento e baixa legibilidade.

- **REFATORADO/**  
  Código refatorado, com funções menores, regras explícitas e tratamento adequado de erros.

## Principais melhorias
- Separação de responsabilidades (SRP)
- Nomes de funções e variáveis mais descritivos
- Eliminação de efeitos colaterais
- Uso de exceções ao invés de prints para controle de fluxo
- Código mais fácil de testar e evoluir

## Observação
O código refatorado possui mais linhas que o original.
Isso é intencional: a prioridade foi clareza e manutenibilidade,
não redução de código.
